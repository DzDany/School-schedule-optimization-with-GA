# School schedule optimization with GA
This project implements a robust School Schedule Optimization system powered by Genetic Algorithms (GA). The primary goal is to automate the complex task of generating conflict-free academic timetables that maximize resource efficiency and satisfy multiple constraints.


## Para ejecutar el proyecto:
Se debe ejecutar el main.py para generar el horario optimizado por el algoritmo bioinspirado, y luego el serve.py para visualizar el horario generado. 

```bash
python main.py
python viewer/serve.py
```
